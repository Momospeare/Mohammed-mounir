Privacy policy

Last updated: November 9, 2026. Plain language, no legalese where it can be avoided. This page is a statement of what the site does — it is not legal advice.

What this site collects

This site itself collects nothing directly — no accounts, no email list, and no form that submits data to this site (the MOLEX waitlist opens your own email app). It does run Google Analytics (via Google Tag Manager), which collects anonymized usage data: pages visited, approximate location (city level), device and browser type, and how you arrived here. It also records how the on-site chatbot Memo is used — which topics visitors ask about and whether Memo could answer — as counts only in Google Analytics (the Memo section below explains the separate question log). It sets first-party cookies (_ga and related) and uses no local storage of its own.

Third-party services

A few parts of the site load from other providers. They may log your IP address and basic request details under their own privacy policies; nothing about you is sent to them by this site beyond the request itself:

  • Map tiles (Esri) — the journey map loads its dark basemap tiles from Esri's servers.
  • Map library (unpkg) — the Leaflet map library and marker-cluster plugin load from the unpkg CDN.
  • Analytics (Google Tag Manager / Google Analytics 4) — loads from Google's servers and records anonymized usage as described above, under Google's privacy policy.
  • Hosting (GitHub Pages) — the site is hosted on GitHub Pages, which serves the files and may keep standard server logs.
  • Outbound links — links to LinkedIn, GitHub, and certificate-verification pages only load if you click them.

To opt out of Google Analytics, install Google's Analytics Opt-out Add-on (opens in new tab) or block third-party cookies in your browser settings.

Memo, the on-site chatbot

Memo runs in your browser. It matches what you type against a fixed list of scripted answers about Mohammed's work. What you type is sent to Mohammed's own server (a Cloudflare Worker) so he can see which questions Memo couldn't answer and improve it — before it is stored, email addresses, phone numbers and links are removed, and it is kept only as a short text log with the topic and whether Memo had an answer. No name, account or contact details are collected, and the log is never shared. Separately, Google Analytics receives only counts: which topic your question was about (for example, "police" or "projects") and whether Memo had an answer for it. Your actual words are never sent to Google.

Data deletion

Because the site itself stores no personal data about visitors, there is nothing to delete from it. Usage data collected by Google Analytics is held by Google under its own policy; the opt-out above stops future collection. If you believe otherwise or have a question about your data, contact Mohammed via LinkedIn (opens in new tab) and it will be looked into.

Children

This site is a professional portfolio. It is not aimed at children, and it collects no data from anyone, of any age.

Changes

If how this site handles data changes — for example, if analytics or a contact form is added — this page will be updated and the date above will change.
