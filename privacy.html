Privacy policy

Last updated: November 7, 2026. Plain language, no legalese where it can be avoided. This page is a statement of what the site does — it is not legal advice.

What this site collects

Nothing, directly. This is a static portfolio site. It has no accounts, no forms, no email list, and no analytics running — there is no Google Tag Manager or Google Analytics wired in at the moment. It sets no cookies and uses no local storage.

Third-party services

A few parts of the site load from other providers. They may log your IP address and basic request details under their own privacy policies; nothing about you is sent to them by this site beyond the request itself:

  • Map tiles (Esri) — the journey map loads its dark basemap tiles from Esri's servers.
  • Map library (unpkg) — the Leaflet map library and marker-cluster plugin load from the unpkg CDN.
  • Hosting (GitHub Pages) — the site is hosted on GitHub Pages, which serves the files and may keep standard server logs.
  • Outbound links — links to LinkedIn, GitHub, and certificate-verification pages only load if you click them.

If analytics are ever added, this page will be updated to say what is collected and how to opt out.

Memo, the on-site chatbot

Memo runs entirely in your browser. It matches what you type against a fixed list of scripted answers about Mohammed's work. Nothing you type is sent anywhere, stored, or shared — there is no server behind it.

Data deletion

Because the site stores no personal data about visitors, there is nothing to delete. If you believe otherwise or have a question about your data, contact Mohammed via LinkedIn and it will be looked into.

Children

This site is a professional portfolio. It is not aimed at children, and it collects no data from anyone, of any age.

Changes

If how this site handles data changes — for example, if analytics or a contact form is added — this page will be updated and the date above will change.
